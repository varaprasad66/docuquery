## How to run

| Task | Command (from tool root) |
|---|---|
| Full stack | `docker compose up --build` |
| Infra only | `docker compose up db redis -d` |
| Backend dev | `cd backend && pip install -e . && alembic upgrade head && python run.py` (port 8100) |
| Frontend dev | `cd frontend && npm install && npm run dev` (port 5173, proxies API) |
| All tests | `python scripts/run_tests.py` (unit, then integration vs disposable DB) |
| Unit only | `python scripts/run_tests.py unit` |
| Eval | `python scripts/run_eval.py 6` (hit@1 85% / hit@3 95% / hit@6 100%) |
| Lint backend | `cd backend && ruff check . && ruff format --check .` |
| Lint/build frontend | `cd frontend && npm run lint && npm run build` |
| Edition smoke | `python scripts/edition_check.py`; live demo: `python scripts/live_demo.py` |

## Config rules

- One `Settings` class in `backend/app/config.py`; every value overridable via `backend/.env`
  (template: `backend/.env.example`). Add new config **there only** — never read env vars ad hoc.
- Every schema change needs an Alembic migration in `backend/migrations/versions/`.
- Feature gating goes through `app/editions.py` (`EDITION`), never ad-hoc checks.
